# 初めてAIで競艇の予想に挑戦。1万円は増やせるのか？

- 研究番号：003
- 公開日：2026年10月27日
- カテゴリ：くらし研究室／AI・データ検証
- 研究状況：研究中（実際の投票はまだ0円）
- 研究者：太郎所長

> **初期資金は1万円。入金はした。でも、まだ1円も賭けていない。**
>
> 最初に検証したいのは「AIが予想できそうか」ではなく、「過去データを使った予測が、未経験のレースでも本当に通用するのか」です。

## 研究のきっかけ

競馬、競輪、競艇。データを調べれば予想の精度を高められる可能性はあるのか。今回は、その中から競艇（ボートレース）を研究対象に選びました。

ただし「競艇が他の公営競技より簡単に勝てる」と確認できたわけではありません。**それ自体が今後検証すべき仮説**です。

単純に「1号艇の勝率が高い」という情報を並べても、研究の目的には届きません。選手がどんな条件で勝ちやすく、何が変わると結果が変わるのか。膨大なレースを条件別に調べたいと考えました。

## 1万円の研究資金を公開する

| 項目 | 2026年10月27日時点 |
| --- | ---: |
| 口座への入金額 | 10,000円 |
| 実際の購入額 | 0円 |
| 的中払戻 | 0円 |
| 投票損益 | 0円 |
| 入金分の残高 | 10,000円 |

資金は入金済みですが、予測精度が確認できるまでは使わない方針です。これは仮想投票ではなく、将来の実投票に備えた研究。ただしAI自身が口座を操作するわけではなく、購入判断は人が行います。

今後は購入した場合、**予想・購入額・的中/不的中・払戻・損益・累計回収率**を記録します。都合のいい勝ちレースだけを抜き出すことはしません。

## どんな情報を調べるのか

特に重視するのは次の条件です。

1. **選手**：登録番号ごとの実績、級別、当地での成績、近況。
2. **モーター**：2連対率だけでなく、ボートレース場・使用期間との組み合わせ。
3. **競艇場**：場ごとのコース傾向や水面の特徴。
4. **天気・水面**：風向き、風速、波など。

これらを単独で比べるだけでなく、「ある選手が、ある場の、ある条件で走ったとき」の組み合わせを調べます。

注意が必要なのは天候です。レース終了後の記録に載っている風や波を、事前に分かっていた情報としてAIに渡すと、実際にはできない予測をしたように見えてしまいます。学習には**投票前に利用可能だった情報だけ**を使う必要があります。

## 約30年前の公式データは使えるのか

BOAT RACE公式サイトでは過去の番組表と競走成績のダウンロードが案内されています。そこで、次の4日間の公式データを実際に読み込みました。

- 1997年5月1日
- 2005年5月1日
- 2015年5月1日
- 2025年5月1日

重要なのは、**約30年分を全部取得して分析したわけではない**ことです。今回は年代を離した4日間の書式を読み、共通のデータベースに変換できるか検証した段階です。

## 今回、数字で確認できたこと

| 検証項目 | 実測値 |
| --- | ---: |
| 公式データから照合できたレース | 671レース |
| 出走・結果を紐づけた艇数 | 4,026艇分 |
| 異なる選手の登録番号 | 1,827人 |
| 対象となった競艇場 | 24場 |
| 1着を確認できたレース | 670レース |
| 1997年と2025年の両方に登場した登録番号 | 26人 |

初めは、数値の一部を取得できないレースがありました。調べると、数値自体の欠損ではなく「モーターの数値とボート番号の間にスペースがない」といった昔のデータの書式が原因でした。読み取りプログラムを修正し、今回の671レースについては、6艇分の出走情報と結果をすべて対応付けられました。

また、1997年と2025年のサンプル日に共通して登場する選手登録番号が26人ありました。28年を隔てた結果を同一の選手として結べることも確認できました。

ただし1997年より前にデビューした選手は、今回確認した公式データだけではデビューからの全履歴がそろいません。この不足をどう扱うかも研究課題です。

## 当てることと、儲けることは別の検証

この研究は2段階で進めます。

**第1段階：的中の予測精度を検証する。** 過去の結果を覚えさせただけでは意味がありません。学習していない、その後のレースを予測させ、実際の結果と比較します。予想するレースを絞り込む方法も、後から都合よく選ばずに検証します。

**第2段階：実際の購入時点のオッズと照合する。** 仮に勝つ確率が高くても、配当が低ければ長期的には損をする可能性があります。そこで初めて、購入額と回収率まで計算します。

公式の競走成績にある当たり券の「払戻額」は、レース前に全買い目へ提示されていたオッズとは異なります。このデータも別途必要です。

## 今の結論：勝てるとはまだ言えない

現時点で証明できたのは「離れた年代の公式データを共通の形式へ整理できる」ということまでです。

- AI予測の的中率が高いとは、まだ確認できていません。
- 1万円を増やせる根拠は、まだありません。
- 予想や購入を勧められる段階ではありません。

ここをごまかして「AIで必勝」と書いたら、研究ではなく宣伝になってしまいます。

## 次回の研究

まずは公式データの利用条件を確認し、過去のデータを適切に長期間入手できる方法を整えます。それからモーターの交換時期、選手の長期履歴、過去の予測で使える情報の時点を整理します。

十分なデータがそろったら、**過去の未知レースに対してどれくらいの確率で予測できたか**を公開します。結果が悪ければ、その失敗も記録します。
